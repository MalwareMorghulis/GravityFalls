## DGA_Detection by MiaWallace0618 on Github: https://github.com/miaWallace0618/DGA_Detection
- Download the Pre-Built Docker Image from Author's Pre-Built Docker Image on Google Drive - https://drive.google.com/file/d/1DXPTtse12P29IwuEX8IdJNiiVWB_OaNS/view?usp=sharing
- After downloading Google Drive Docker TAR file:
-- $ sudo docker load < path_to_dga_detection.tar
-- $ sudo docker run -p 80:80 dga_detection:latest
-- $ sudo snap install postman
--- Open Postman and point to http://127.0.0.1:80
--- Provide input files through Postman.
---- HTTP Method: POST
---- HTTP URL: http://127.0.0.1:80/predict
---- HTTP Body Type: form-data
---- Body Key (typed): file
---- Body Key Type (dropdown option): File
---- Body Value (selected file): INPUT_FILE
---- **NOTE**: the input file is just raw text row-by-row list of domains (input does not have a header line, remove "domains" if it exists as the first cell).
---- **Details**: When using Postman, select the body tab under the GET request field. Check the radio button for "form-data". The Key-Value Table will appear. Key name must be "file" (lowercase), but Postman also provides a dropdown within the same box. Set the Key field's dropbox with type: "File" (capitalized). In the Value field, you can add the DGA analysis file with the "Select Files" button. Then click "SEND" to submit the DGA analysis file to DGA_Detection Docker instance on testbed workstation. The response will return as an array in JSON.

## COSSAS DGAD Docker (Bulk Domain Check, online)
- $ cat ../PATH/INPUT.csv | sudo docker run -i registry.gitlab.com/cossas/dgad:4.1.1 client -fmt csv -f - --domains_column domains > OUTPUT.json
-- **NOTE**: This tool expects the input or CSV file to have a header line of "domains".
-- This will pull the image if it cannot find one locally or offline.

### COSSAS Debugging (Execution)
- Error:
-- "CRITICAL: root: you must have a {domains_column} column in your csv/jsonl file"
- Reason:
-- The file is looking for the "domains" keyword, this is potentially an encoding error as well.
- Remediation:
-- If the COSSAS DGAD does not cooperate, then use the optional explicit argument: "--domains_column domains". The tool executes it as implied, but may help.
-- Use Notepad++ to convert the file from "Windows (CR LF)" to "Unix (LF)" and change encoding from "UTF-8 BOM" to "UTF-8", check that the first token is "domains", then save files again.

### COSSAS Debugging (Skipping)
- Error:
-- "WARNING:root:will skip domains ['domain, 'domain', ... , 'domain']"
- Reason:
-- COSSAS DGA tool cannot handle domain length (ie: crazy-long ISP router names).
- Remediation:
-- Skip domain or unable to test.
