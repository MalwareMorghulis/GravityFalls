# Instructions - Tool 5 (mia aligner)
This HTML tool assumes you took the output from the mia web server and saved it to a TXT file.

Note: mia's detector server doesn't send back JSON with [ ] brackets, so no other JSON file will work with this converter.

This HTML tool merges the prediction outputs with the input domains list. mia iterates through each domain when giving results back (e.g., your first result prediction is for your first domain).

Prerequisites:
1) Install & run the mia DGA detector tool (it's a web server)
2) Send your domain or domains list to mia through HTTP requests in Postman.
3) Take your output and save it to a TXT file or JSON file.

How to run this tool:
4) Open this HTML tool.
5) Drag mia output into the top upload field.
7) Drag your test dataset back into the bottom field
6) Export the CSV!

Please do not try to convert other JSON files (not from mia tool) because it will not work.
