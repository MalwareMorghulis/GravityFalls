# Instructions - Tool 4 (Exp0se JSON-to-CSV cCnverter)
This HTML tool is a simple drag-and-drop to convert the JSON output from Exp0se to CSV instead.

1) Drag Exp0se JSON output into the upload field.
2) Export the CSV or try again!

Please do not try to convert other JSON files (not from Exp0se tool) because it will not work.

This HTML tool was generated by Claude AI (and tested for this specific experiment).
