# Instructions - Tool 6 (DGAD JSON-to-CSV Converter)
This HTML tool assumes you took the output from the mia web server and saved it to a TXT file.

Note: DGAD runs as a docker container.

This HTML tool merges the prediction outputs with the input domains list. DGAD runs domains however it wants... so know domains may be out of order.

Prerequisites:
1) Export your DGAD data as a JSON file.

How to run this tool:
2) Open this HTML tool.
3) Drag DGAD output into the top upload field.
4) Check-off whatever fields you want - DGAD tokenizes each portion of a domain (delimited by ".") so you might have a lot of excessive fields...
5) Export the CSV!

Please do not try to convert other JSON files (not from DGAD tool) because it will not work.

This HTML tool was generated by Claude AI (and tested for this specific experiment).
