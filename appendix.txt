# Appendix: Replication of Study

# Virtual Lab Specifications
- VMware Workstation Pro 17.6.2 or VirtualBox
- Ubuntu Desktop 24.04.03 LTS 64-bit (amd64)
- CPU: 2 core, 2 processor
- RAM: 8GB
- Storage: 120 GB
- vNIC: Bridged Mode (does not matter)
- General Rule-of-Thumb for Type-2 Hypervisors: Ensure that the VM has no more than 50\% of all physical resources allocated. Due to operating both the Guest and Host OS simultaneously.
- VMware Workstation Pro was free for personal use through Broadcom, as of November 2024.

## DGA_Detection by MiaWallace0618 on Github: https://github.com/miaWallace0618/DGA_Detection
- Download the Pre-Built Docker Image from Author's Pre-Built Docker Image on Google Drive - https://drive.google.com/file/d/1DXPTtse12P29IwuEX8IdJNiiVWB_OaNS/view?usp=sharing
- After downloading Google Drive Docker TAR file:
-- $ sudo docker load < path_to_dga_detection.tar
-- $ sudo docker run -p 80:80 dga_detection:latest
-- $ sudo snap install postman
--- Open Postman and point to http://127.0.0.1:80
--- Provide input files through Postman.
---- **NOTE**: the input file is just raw text row-by-row list of domains (input does not have a header line).
---- **NOTE**: When using Postman, select the body tab under the GET request field. Check the radio button for "form-data". The Key-Value Table will appear. Key name must be "file" (lowercase), but Postman also provides a dropdown within the same box. Set the Key field's dropbox with type: "File" (capitalized). In the Value field, you can add the DGA analysis file with the "Select Files" button. Then click "SEND" to submit the DGA analysis file to DGA_Detection Docker instance on testbed workstation. The response will return as JSON.

- $ docker load < cossas_dgad.tar
